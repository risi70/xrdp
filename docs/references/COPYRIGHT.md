# Copyright and Offline Copies

Do not commit vendor PDFs, HTML mirrors, manuals, screenshots, or other copied
third-party documentation unless the license explicitly permits redistribution
in this repository.

Allowed in git:

- URLs and citations.
- Short factual summaries.
- Local notes written by this project.
- Scripts/manifests that let an operator fetch references into ignored folders.

Not allowed in git by default:

- Full Microsoft Learn/Open Specifications pages or PDFs.
- IGEL documentation exports.
- UDS Enterprise/Virtual Cable manuals.
- Vendor screenshots or proprietary guides.
- Any document obtained under a customer portal, login, EULA, or support
  contract unless redistribution is explicitly permitted.

If offline copies are needed, place them under the relevant supplier
`originals/` directory. These directories are ignored by git.
